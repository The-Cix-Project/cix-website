# ADR 0007: Homepage routes by evaluator intent

- Status: Accepted
- Date: 2026-09-01
- Evidence: [`cc76564`](https://github.com/The-Cix-Project/cix-website/commit/cc76564)

## Decision

The homepage offers three explicit next steps: Run it, Evaluate it, and Integrate it. Each route leads to the relevant evidence page.

## Consequences

Visitors do not need to read the entire technical story before reaching a useful action.
