Before you begin

Know the current target.

Use a disposable target for your first installation. Keep console access available while setting up networking and authentication.

UEFI x86-64

The current installer targets UEFI x86-64. Proxmox users should use OVMF with Q35.

Reachable API

The first-use path needs a management address and a client that can reach the REST daemon.

Console access

Keep video or serial console access available for installation, recovery, and authentication bootstrap.

Offline first use

Without a network or a prebuilt cache entry, a seed is needed for the first container; on first boot, check whether the cached C library was installed in the base image.

Fresh-install defaults

Check the first catalogue sync.

A fresh host with no saved package or schedule configuration starts with the public Cix recipe catalogue and Cix Cache. It creates an ordinary recipe-sync schedule that syncs the catalogue at first boot and every six hours, so a new host can find current recipes without hand-entering service URLs.

The defaults are pull-only: publishing is disabled. Operators can replace, clear, change, or remove the sources and schedule through the API or CLI. If the first sync runs before DNS or outbound networking is ready, check cixctl pkg sync-status and run cixctl pkg sync --wait after connectivity is available.
