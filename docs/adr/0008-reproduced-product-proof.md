# ADR 0008: Show reproducible product proof

- Status: Accepted
- Date: 2026-09-01
- Evidence: [`94a562c`](https://git.home.arpa/itdlabs/cix-website/commit/94a562c)

## Decision

The site may show a captured CLI → REST → dashboard workflow only when it records the Cix source revision, capture date, disposable fixture, and exact API contract links.

## Consequences

The proof page demonstrates behaviour without presenting a screenshot as a substitute for source or API documentation.
