# ADR 0010: State security support and human purpose precisely

- Status: Accepted
- Date: 2026-09-02
- Evidence: [`b3c2020`](https://git.home.arpa/itdlabs/cix-website/commit/b3c2020)

## Decision

Mention the documented Secure Boot-capable installed boot chain, and pair the technical story with restrained human language (“Make computing fun again.”) without replacing evidence with slogans.

## Consequences

Security support is visible in the product path, while warmth improves memorability without changing technical claims.
