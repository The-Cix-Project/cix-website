# ADR 0018: Approve “Systems, directly.” as the master tagline

- Status: Accepted
- Date: 2026-09-03
- Evidence: Product decision recorded in website issue #25

## Decision

Retain **Systems, directly.** as Cix’s master brand line. Use it with the product lockup when category clarity matters:

> Cix — Systems, directly. An open-source Linux operating system built from source.

## Consequences

The tagline remains distinctive and faithful to Cix’s direct-control thesis. It must not be used as the only above-the-fold product explanation; the open-source Linux definition and a concrete operator benefit should accompany it. Supporting lines remain **Built from source.** and **Build what you run.**
