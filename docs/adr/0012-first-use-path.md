# ADR 0012: Get Cix leads from boot to first useful action

- Status: Accepted
- Date: 2026-09-02
- Evidence: [`31b9725`](https://github.com/The-Cix-Project/cix-website/commit/31b9725)

## Decision

The download page provides a short first-use path: install and connect, run a workload, then build or update. The source repository remains the technical manual authority.

## Consequences

New users get an actionable route without duplicating the Cix guides or turning the marketing site into a second documentation system.
