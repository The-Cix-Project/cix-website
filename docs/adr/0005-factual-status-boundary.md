# ADR 0005: Status claims are evidence-calibrated

- Status: Accepted
- Date: 2026-09-01
- Evidence: [`7e493f3`](https://git.home.arpa/itdlabs/cix-website/commit/7e493f3)

## Decision

Project status separates shipped foundations, verified behaviour, active work, and explicit boundaries. A capability is not presented as complete merely because it is planned or described in an ADR.

## Consequences

The status page is a trust surface and links readers to roadmap, ADR, API, and test evidence.
