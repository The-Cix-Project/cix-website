Recipes

Start with a versioned input.

A package recipe records its source, checksum, version, dependencies, and build environment. New package builds use CPDL in build.cbs, executed by CBS; image recipes are JSON. Older published shell recipes are historical; Cix no longer builds them. A cached artefact may still be usable when it matches a published recipe and checksum. See the recipe guide for the format and supported fields.

build.cbsCPDL 1.0CBSJSON imagescix-recipes
02

Artefacts

Use a cache hit or build from source.

Cix Cache may provide a prebuilt package whose identity and SHA-256 match the recipe. For a current CPDL/CBS recipe, a cache miss can trigger a source build. Older shell artefacts are cache-only and are not rebuilt by cixd. Installer releases are signed and verified before publication.

recipeartefactSHA-256minisignrelease gate
03

Self-hosting

Build the platform from a Cix host.

A running Cix host can build cixd, cixctl, the dashboard, the kernel, and a fresh installer ISO. This path is useful when you need a reproducible local build or cannot use a prebuilt artefact. Follow the build guide for the required inputs and the current limits.

hostbuildkernelrootfsISO assemblyCPDL 1.0 via CBS

Build feedback

Follow the work while it runs.

The dashboard opens one floating log view for a running build. It follows the selected job, identifies which build produced the output, shows the current stage and elapsed time, and keeps the live log available while you inspect the rest of the host.
