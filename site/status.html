Will Cix fit your host?

Cix targets individual x86-64 UEFI machines and VMs. Check the storage controller, network interface and isolation requirements for your workload before installing.

Before you install

Check the machine and workload.

Cix is an alpha release. Start with a spare machine or VM, keep console access, and back up the target disk. Verify the installer.

  • Boot and storageUse x86-64 UEFI firmware. For Proxmox, choose OVMF with Q35. Check your disk controller against the installation guide.
  • Networking on first bootYou need a reachable management interface. Configure a resolver for online recipe and package fetches. For an offline first container, prepare a package seed.
  • Physical devicesCheck the driver for each NIC, GPU or radio you intend to assign. For wireless deployments, validate client association, DHCP and traffic to the wired network on your target hardware.
  • Isolation and scaleWorkloads share one Linux kernel. Direct device grants give containers access to physical hardware. Cix manages an individual host and does not provide multi-host scheduling.
  • Maintenance windowsA same-kernel handover can preserve running containers. Plan for management connections to drop during the switch and for a reboot when the kernel changes. Plan host and workload updates.
  • Automation accessMCP starts disabled. Give an agent a directory identity and grant its groups only the operations it needs. Review the permission model.
  • Source buildsCurrent package builds use CPDL recipes executed by CBS. Use a signed installer to get started or build packages and images on a Cix host.
