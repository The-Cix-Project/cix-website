Pages and guides.

For a first install, start with Get started. For a working host, choose a guide by the task you need to complete.

  1. 1. Home — Cix on a dedicated container host.
  2. 2. Try Cix — Choose a VM or a hardware trial and check agent access.
  3. 3. Get started — Boot the host and run a first container.
  4. 4. Download Cix — Download the UEFI installer, signature and release key.
  5. 5. Trust and limits — Review agent permissions, isolation and release integrity.
  6. 6. Operate — Plan host upgrades, workload restarts and persistent state.
  7. 7. API — Use REST or native MCP with directory-backed permissions.
  8. 8. Build — Follow package outputs into the root image and boot slot.
  9. 9. Resources — Assign hardware, place volumes and adopt an existing filesystem.
  10. 10. Why Cix — Decide whether the operating model fits your machine.
  11. 11. Architecture — Trace a client request from cixd to the kernel.
  12. 12. Services — Run directory, DNS, DHCP and time services in containers.
  13. 13. Project status — Inspect recorded host runs and current limits.
  14. 14. Product proof — Inspect a host upgrade, agent permissions and a dashboard capture.
  15. 15. Contribute — Report a result or prepare a signed-off patch.
  16. 16. Sitemap — Find every public page.
  17. 17. Not found — Return to the site from a missing address.
