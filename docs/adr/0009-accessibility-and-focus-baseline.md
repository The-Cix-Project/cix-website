# ADR 0009: Accessibility is a release baseline

- Status: Accepted
- Date: 2026-09-02
- Evidence: [`f0f0b49`](https://github.com/The-Cix-Project/cix-website/commit/f0f0b49)

## Decision

Keyboard navigation, focus visibility, skip links, responsive menus, semantic labels, and meaningful image alternatives are part of the site’s baseline—not post-launch polish.

## Consequences

Interactive behaviour remains progressive and dependency-free, while manual browser and assistive-technology checks remain required.
