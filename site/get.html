Release keys

Know which key signed the media.

Installers published from 6 September 2026 onward are signed by cix-release-2026-09.pub, key id 0b19db46b2b6db6c. For first-time trust, compare that identifier with a trusted Cix release announcement or obtain the public key through a separately trusted channel. Then use the command above to verify the ISO and its detached signature.

Older installers may have been signed by cix-release.pub. Keep that public key only to verify those historical downloads; it does not sign current media. Public keys can be published openly because they verify signatures. The corresponding signing private key is never published.

02 / Install

Check your machine first.

These are the currently supported installation paths. Read the guide before selecting a target disk.

UEFI x86-64

Cix is UEFI-only. For Proxmox, use OVMF with Q35 rather than legacy BIOS/i440fx.

Target storage

Supported paths include VirtIO Block, VirtIO-SCSI, SATA/PATA, NVMe, and software RAID.

Management network

The installer needs a static IP, prefix, gateway, and interface. Current releases include Intel I225/I226 2.5GbE support; other NICs remain hardware-specific, so check the installation guide before choosing a machine.

Console

Video and serial installation are supported. Secure Boot enrolment follows a specific first-boot procedure.

Before you begin

Know what the first boot needs.

Cix is a beta operating system. Have a supported machine, console access, a management network, and a backup of anything on the target disk.

01

Use a spare target

The installer changes the selected disk. Do not use a disk containing data you need until you have confirmed the target and made a backup.

02

Keep console access

Video or serial access is needed for installation, recovery, and authentication setup.

03

Expect beta behaviour

Hardware support is narrower than the documented list. Check the installation guide for your machine before committing it.

04

Ask the next question

Use the quickstart after boot, then use the administration guide when you are ready to run workloads.

Beta release

Use it with care.

Cix is available for testing and community use, but it is still changing. Expect unsupported hardware, incomplete features, and changes between releases. Keep console access and backups available, and verify every installer before booting it.
