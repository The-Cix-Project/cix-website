# ADR 0002: Product story follows source evidence

- Status: Accepted
- Date: 2026-09-01
- Evidence: [`fd316fd`](https://github.com/The-Cix-Project/cix-website/commit/fd316fd)

## Decision

The website explains Cix through its mission, architecture, roadmap, guides, ADRs, code, and API—not generic Linux marketing. Material claims link to an authoritative source or dated proof.

## Consequences

Copy can be persuasive without becoming a second specification. Unverified capability, intent, and roadmap language must remain visibly distinct.
